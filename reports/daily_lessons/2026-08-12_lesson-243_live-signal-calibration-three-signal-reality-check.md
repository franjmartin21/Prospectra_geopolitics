### Code Note for Pipeline 4 — Adding the May 2026 Trade Deal Context

The congress.gov API query in Lesson 238 monitored for *tightening* legislation. Now that a trade deal is partially live, Pipeline 4 needs a new component: the **Trade De-escalation Counter**.

```python
# Add to Pipeline 4 — Trade De-escalation Counter
# Monitors BIS Entity List NET direction: additions minus removals
# A net-removal trend is a Signal 3 amplifier (de-escalation happening)
# A net-addition trend is a Signal 3 dampener (tech decoupling continuing despite trade deal)

def compute_entity_list_net_direction(gdelt_results):
    """
    Uses GDELT keywords to estimate BIS Entity List activity direction.
    Input: GDELT news query results filtered to 'BIS Entity List' keyword.
    """
    # Keyword weighting:
    # 'Entity List added' / 'restricted' / 'blacklisted' → escalation signal (+1)
    # 'Entity List removed' / 'license restored' / 'Entity List exemption' → de-escalation signal (-1)
    
    escalation_keywords = ['added to entity list', 'blacklisted', 'restricted', 'enforcement action', 'penalty']
    deescalation_keywords = ['removed from entity list', 'license restored', 'exemption granted', 'waiver', 'removed restriction']
    
    net_score = 0
    for article in gdelt_results:
        headline = article.get('headline', '').lower()
        for kw in escalation_keywords:
            if kw in headline:
                net_score += 1
        for kw in deescalation_keywords:
            if kw in headline:
                net_score -= 1
    
    # Normalize to 1-5 scale where:
    # 5 = strong escalation (many additions, few removals)
    # 1 = strong de-escalation (many removals, few additions)
    # 3 = neutral (mixed signals — like the current trade deal with continued tech controls)
    
    # The current environment (May 2026): net_score should be ~positive
    # (trade deal = some de-escalation, but BIS enforcement = escalation dominant in tech)
    # Expected Pipeline 4 score: 3.8–4.2 despite the trade deal
    return min(5.0, max(1.0, 3.0 + (net_score / 10)))
```

This component distinguishes between the **agricultural trade de-escalation** (Signal 3 Level 2) and the **technology escalation** (Pipeline 4 high score). Without this distinction, the pipeline conflates two trends moving in opposite directions. With it, the analyst can see the bifurcation in real time.
