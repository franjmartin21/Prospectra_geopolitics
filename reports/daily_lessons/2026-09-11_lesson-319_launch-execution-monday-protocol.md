## I. Complete the Draft Now (The Next 90 Minutes)

Lesson 318's Thursday tasks were: pull GRI scores, select a country, write Components 1 and 2, send the first 10 outreach messages. If any of those are incomplete, do them first. This lesson assumes the country is selected and Components 1–2 exist in draft form.

Today's writing task is Components 3, 4, and 5. They are faster to write than 1 and 2 because the research is done — you already know the mechanism and the historical context from writing Component 2. You are now packaging what you already know into the structured format.

### Component 3: Historical Analogue (90-minute task, 30 minutes)

Do not search for a perfect analogue. Search for the closest analogue with a specific, verifiable data point.

**The search process:**

1. State the mechanism in two words: "central bank independence," "election outcome," "sanctions shock," "military escalation," "diplomatic breakdown."
2. Search memory (or a quick DuckDuckGo search if needed) for: "[mechanism in two words] + [country or comparable EM] + [decade]."
3. Identify one case where this mechanism drove the GRI sub-dimension change you're describing. It does not have to be perfect — it has to be specific. The analogue's value is the calibration point it gives the reader, not its structural identity with the current situation.
4. Find one number: a price, a spread, a rate move, a percentage. That number is what separates an analogue from a reference.

If you cannot find a comparable case in the same country, use the same mechanism in a comparable EM (similar institutional structure, similar currency vulnerability, similar import dependence). Note the comparison is mechanism-based, not geography-based.

**What to write:**
- Sentence 1: The analogue case (country, year, mechanism).
- Sentences 2–3: What the named instrument did in the 30–90 days following that event. One number required.
- Sentence 4: The key structural difference between that case and the current one. This is the most important sentence — it demonstrates you're not just pattern-matching but reasoning about mechanism severity.

Total: 100–150 words. Write it. Move on.

### Component 4: Investment Implication (15 minutes)

You already know the direction from your Component 2 analysis. The work here is precision, not discovery.

**The one-sentence test:** Can you state the implication in this format?

> *We have a [conviction level] view that [specific instrument] will [direction] over [timeframe], because [one-sentence mechanism summary]; the view changes if [falsifiability condition].*

If you can pass that test, you have a Component 4. Fill in the 75–100 word benchmark with the instrument's current price context (where is it trading now relative to recent range), the rationale for the timeframe (why 30 days and not 60?), and the specific falsifiability trigger. Then stop.

**What makes conviction "high" vs "medium" vs "low":**
- **High:** The GRI movement is in the top decile of historical weekly moves for this country; the mechanism directly affects the specific instrument's primary price driver (e.g., a central bank governor resignation directly affects the currency); the historical analogue showed a 15%+ move in the same direction.
- **Medium:** The GRI movement is significant but not extreme; the mechanism has second-order effects on the instrument (e.g., a political event that affects fiscal expectations which affect sovereign spreads); the analogue showed a 5–15% move.
- **Low:** The GRI signal exists but the market may have already priced part of it; the mechanism has complex transmission; the analogue is imperfect.

Post #1 is almost certainly Medium conviction unless you have an exceptionally clean signal. State Medium. The reader trusts a calibrated Medium more than an unjustified High.

### Component 5: Forward Watch (10 minutes)

What is the single most observable event in the next 7 days that will either confirm or contradict the signal? It must be:
- **Named:** Not "central bank communications" but "the Monetary Policy Committee meeting scheduled for September 17."
- **Binary in its implication:** If X happens, signal strengthens. If Y happens, signal weakens. The reader should be able to check the event themselves and update their view.
- **7-day horizon:** If the confirming event is 30 days away, note it as the 30-day watch and find the nearest observable event for this week.

Write 50–75 words. The five components are now complete.

### Final Assembly

1. Open the Substack draft editor (or a Google Doc if Substack isn't set up yet).
2. Paste the five components in order.
3. After Component 5, paste the New Reader Note from Lesson 317 verbatim.
4. Read once for flow. Fix anything that reads as a separate document rather than a single argument.
5. The draft is complete. Do not send it to anyone yet. That is Saturday's task.

## II. The Remaining Outreach (Before Noon Today)

Ten messages remain from the 20-person outreach list. Send them before noon.

The messages sent on Thursday were to Tier 1 contacts — people who know you well enough that the message itself is the signal ("I'm launching something, and you're one of the first to know"). The messages going out today are to Tier 2 contacts — people who know your work but may not be expecting this specific message. The framing is slightly different.

### The Tier 2 Message

**What works:**

> *Hi [name] — I'm launching Prospectra next Monday: a weekly geopolitical risk signal for EM investors. The format is tight — one country, one GRI score move, one investment implication with a falsifiable call, every Monday. I'm inviting 20 people to read the first signal before I open the list. If that's interesting, reply and I'll add you to the launch list. First post: September 14.*

**What to avoid:**

- Don't explain the methodology in the cold message. That's the post's job.
- Don't ask for a favor. ("Would you be willing to share this?") This is an invitation, not a distribution request. The sharing ask comes after they've read Post #1 and found it valuable.
- Don't attach a PDF or a deck. The signal is the proof of concept, not the pitch materials.
- Don't send a mass email with 10 recipients visible to each other. Personal messages, even if you're working from a template.

**Send via:** LinkedIn DM or direct email (not a newsletter tool — this is personal outreach, not mass distribution). If you have both channels, use whichever you've used to communicate with this person before.

**Log the sends:** A simple spreadsheet with columns [Name, Tier, Channel, Sent Date, Response Y/N, Response Date]. You will look at this every Monday for the next 8 weeks to understand your conversion funnel.

### Response Protocol (for responses that arrive before Monday)

If someone responds positively to the outreach message — "yes, add me to the list" or "this sounds interesting" — send one reply:

> *You're on the list. First signal drops Monday morning. Looking forward to your read.*

Nothing else. Do not send a preview. Do not ask what they're hoping to see. The post is the reply.

If someone responds with a question about methodology or the GRI — this is signal interest, not an obstacle:

> *The methodology is in the first post — that's intentional. If the analytical logic isn't clear from reading the signal itself, the methodology note won't help. Read the first signal Monday. If you have questions after, I'd genuinely enjoy that conversation.*

This response is honest and confidence-projecting. It also positions the signal as the credibility demonstration, which it is.

## III. The Monday Morning Machine: What 7:00 AM Looks Like

You will not be writing on Monday morning. Everything that needs to happen Monday is either already scheduled (the Substack post) or already drafted (the LinkedIn post). Monday morning is reading, responding, and logging.

### Sunday Night Checklist (Before You Sleep)

- [ ] Substack post scheduled for 7:00 AM Monday, September 14
- [ ] LinkedIn post drafted and scheduled for 7:30 AM Monday, September 14
- [ ] `signal_track_record` table entry created in Databricks for the Monday signal (signal_id, country, GRI scores, mechanism tag, instrument, direction, timeframe, conviction, falsifiability condition — all fields populated except the outcome fields)
- [ ] Outreach log updated: all 20 messages marked as sent, responses logged
- [ ] Email monitoring set up: you want to know within 30 minutes if anyone replies to the Substack publication email

### Monday 7:00 AM — Go-Live

The Substack post publishes automatically. The LinkedIn post publishes at 7:30 AM automatically.

**What you do at 7:00 AM:**
1. Read the published post on Substack exactly as it appears to a subscriber. Does it render correctly? (This is the one technical check that can only happen after publication.)
2. Check the email notification from Substack that you received it. The email is what subscribers see. Is the formatting correct in the email client? (Mobile and desktop check.)
3. Open the outreach log. Note the time: 7:00 AM.

**What you do NOT do at 7:00 AM:**
- Do not send follow-up messages to the 20 outreach contacts. They either received the signal or they didn't. A follow-up message at 7:05 AM on launch day is noise.
- Do not check social metrics. The signal takes time to reach the reader, and a reader's engagement takes time to show up in analytics. Check once at noon and once at end of day.
- Do not revise the post after publication. The post is a dated record. If there's a factual error, note it in the next post's Forward Watch section as a correction. Do not silently edit the published record.

### Monday Metrics (Check at Noon and End of Day)

**Substack:**
- Open rate (target for a 20-person launch list: >60%)
- Click rate on any links (if you included the Databricks methodology link or the Substack archive link)
- Replies to the email (this is the highest-signal engagement metric — a reader who replies has read the post and had something to say)
- New subscriber sign-ups (from the Substack URL if you shared it anywhere public)

**LinkedIn:**
- Post impressions (this is a lagging metric — do not act on it on Day 1)
- Comments with substantive engagement (someone who names a specific aspect of the signal is your next Tier 1 outreach contact for Post #2)
- Connection requests or DMs from people who saw the LinkedIn post

**The one metric that matters most this week:** How many of your 20 outreach contacts replied to the Substack email or messaged you about the signal? That is your conversion rate from personal outreach to engaged reader. If it's 10/20 or higher, your outreach quality and signal quality are both working. If it's less than 5/20, either the outreach message was off or the signal didn't land — and you need to know which by talking to two people directly.

## IV. What Week 1 Is Actually Testing

Post #1 is not a test of the GRI's predictive accuracy. You will not know whether the investment implication was correct for 30–90 days. Post #1 tests three things that you can measure this week:

**Test 1: Analytical clarity.** Did readers understand what moved, why, and what to do about it — without calling you for clarification? If you receive more than one message asking "what does the GRI score mean?" or "how did you calculate this?" — the signal is not self-explanatory and needs a methodology footnote in Post #2.

**Test 2: Relevance selection.** Did readers find this country and this mechanism interesting? The signal is relevant if readers ask "what does this mean for [related country or asset]?" or "how does this compare to [similar situation]?" — those are engagement signals. The signal is irrelevant if readers respond with "interesting" and nothing else.

**Test 3: Distribution reach.** Did any of the 20 outreach contacts forward the signal to someone who subscribed? One organic forward in Week 1 is a strong early indicator of word-of-mouth potential. More than two organic forwards suggests the signal format is inherently shareable — which changes the Week 2 distribution strategy (you lean harder on LinkedIn and ask the organic sharers for one public recommendation).

Write down your observations from these three tests on Monday evening, before you forget. They are the inputs to Lesson 320, which covers the Post #2 process.

## Investment Implications

### The Publishing Commitment as Capital Allocation

Every week Francisco does not publish is a week the track record clock isn't running. At signal 52, the track record covers a year. At signal 26, it covers six months. Six months of dated, falsifiable signals is the minimum viable dataset for an institutional pitch — it's enough to show win rates by mechanism, enough to demonstrate regime consistency (does the model work in multiple macro environments?), and enough to tell a credible story about methodology.

**The opportunity cost calculation:**

If the first signal is September 14 and the institutional pitch threshold is 26 signals, the earliest possible pitch to an institutional buyer is **Week 26 — approximately March 2027**. Every week of delay slides that date by one week.

This is not a reason to rush a bad signal. It is a reason to not let "not quite ready" become a two-week delay. The signal architecture is defined. The format is defined. The analytical process is defined. The track record starts when the first signal publishes.

**The compounding dynamic:**

A signal that is 80% as good as the ideal but published on September 14 produces a data point. A signal that is 100% ideal but published on September 21 produces a data point one week later. In a 26-signal track record, one missed week costs roughly 4% of the dataset. In a 52-signal track record, it costs 2%. The loss is bounded — but it is a real loss.

The asset being built is the track record. The track record requires publication. Publish.

## Databricks Angle

**Build: `prospectra.gold.outreach_conversion_log` — The Distribution Funnel Table**

Start logging your outreach and response data in Databricks from Day 1. Over 52 weeks, this table tells you which contacts convert to engaged readers, which channels drive organic growth, and which signal formats generate the most inbound interest.

Schema:

```python
outreach_schema = StructType([
    StructField("contact_id", StringType(), False),          # anonymized (e.g., "T1-001")
    StructField("tier", IntegerType(), False),                # 1, 2, or 3
    StructField("channel", StringType(), False),              # "linkedin", "email", "twitter"
    StructField("outreach_date", DateType(), False),
    StructField("signal_id", StringType(), True),             # links to signal_track_record
    StructField("response_received", BooleanType(), False),
    StructField("response_date", DateType(), True),
    StructField("response_type", StringType(), True),         # "subscribed", "question", "forward", "positive_no_action", "no_response"
    StructField("organic_referral", BooleanType(), True),     # did this contact refer another subscriber?
    StructField("became_paid", BooleanType(), True),          # for future paid tier tracking
    StructField("notes", StringType(), True)
])
```

Run a weekly query after 8 signals:

```python
funnel = spark.sql("""
  SELECT
    tier,
    channel,
    COUNT(*) AS outreach_sent,
    SUM(CASE WHEN response_received THEN 1 ELSE 0 END) AS responses,
    ROUND(100.0 * SUM(CASE WHEN response_received THEN 1 ELSE 0 END) / COUNT(*), 1) AS response_rate_pct,
    SUM(CASE WHEN response_type = 'subscribed' THEN 1 ELSE 0 END) AS subscriptions,
    SUM(CASE WHEN organic_referral THEN 1 ELSE 0 END) AS referrals
  FROM prospectra.gold.outreach_conversion_log
  GROUP BY tier, channel
  ORDER BY subscriptions DESC
""")
```

This table is the distribution analytics layer. At signal 26 (six-month pitch point), it tells you which channels and which contact profiles convert. That intelligence shapes how you allocate outreach time in Year 2 — double down on what works, retire what doesn't.
